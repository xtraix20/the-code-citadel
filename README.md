# 🏰 The Code Citadel: A Developer's RPG Journey

Bienvenido a **The Code Citadel**, una plataforma de aprendizaje gamificada diseñada para transformar a desarrolladores aspirantes en legendarios **Arquimagos del Código**. Inspirada en la estética rústica medieval y la progresión de los gimnasios Pokémon.

## 📜 El Lore del Reino
En un mundo fragmentado por errores de sintaxis y fugas de memoria, la Orden de los Programadores ha erigido la Ciudadela. Tu misión es viajar a través de los diferentes reinos, derrotar a los Jefes de Gimnasio (Gym Leaders) y recolectar las Medallas Reales para demostrar tu valía.

## 🗺️ Los Reinos de la Ciudadela
Cada lenguaje de programación es una región con sus propios desafíos y peligros:

- **🏛️ The Oracle's Java Citadel**: El bastión de la estabilidad y los tipos estáticos.
- **🐍 The Serpent's Grove (Python)**: Tierras de sintaxis limpia y magia de datos.
- **🕸️ The JavaScript Dungeons**: Un laberinto asíncrono lleno de promesas y dragones.
- **🛡️ The Rust Fortress**: Donde la memoria está protegida por leyes inquebrantables.
- **⚔️ The C++ Cathedral (LEGENDARY)**: Solo para los más valientes. Gestión de memoria manual.
- **🏃 The Go Highlands**: Rapidez y concurrencia simplificada.
- **💀 The Security Catacombs**: El arte de la defensa y el ataque ético.

## 🎮 Mecánicas de Juego
- **Honor (XP)**: Gana honor resolviendo misiones de código.
- **Rangos**: Asciende de *Escudero* a *Caballero*, *Paladín* y finalmente *Arquimago*.
- **Pistas del Oráculo**: Si te atascas, puedes pedir ayuda, pero te costará puntos de Honor.
- **Gym Badges**: Derrota al Boss final de cada reino para obtener su medalla única.

## 🛠️ Tecnologías Utilizadas
- **Frontend**: React + Vite
- **Styling**: TailwindCSS v4 + Medieval Design System
- **Estado**: React Hooks & LocalStorage Persistence
- **Engine**: Custom Regex & Keyword Validation Engine

## 🚀 Instalación y Despliegue
1. Clona el repositorio.
2. Ejecuta `npm install` para forjar las dependencias.
3. Inicia el reino con `npm run dev`.
